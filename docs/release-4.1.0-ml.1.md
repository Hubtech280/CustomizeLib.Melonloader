## English

CustomizeLib for **PvZ Fusion 4.1** and **MelonLoader 0.7.3**. BepInEx is not required.

- Adapts the library to the 4.1 game API without clearing the new Rogue progression.
- Legacy Rogue buffs appear under General in the Almanac. This does not migrate mods to the new Rogue system.

Close the game, remove any older copy of CustomizeLib, and place `CustomizeLib.MelonLoader.dll` from the ZIP in `Mods`. Older mods may still need their own 4.1 update.

## Français

CustomizeLib pour **PvZ Fusion 4.1** et **MelonLoader 0.7.3**. BepInEx n’est pas nécessaire.

- Adapte la bibliothèque à la 4.1 sans effacer la progression du nouveau mode Rogue.
- Les anciens bonus Rogue apparaissent dans la catégorie Général de l’almanach. Les mods qui veulent utiliser le nouveau système Rogue doivent s’y adapter.

Fermez le jeu, retirez l’ancienne copie de CustomizeLib et placez le fichier `CustomizeLib.MelonLoader.dll` du ZIP dans `Mods`. Les anciens mods peuvent nécessiter leur propre mise à jour pour la 4.1.
