# CustomizeLib / PvZ Fusion 4.1 — local compatibility preview

## Target and preservation

- Game: PvZ Fusion 4.1.
- MelonLoader 0.7.3 runtime copied from the existing working installation.
- No old mods or old generated game assemblies copied. The 4.1 assemblies
  were generated from its own GameAssembly.dll / metadata on first launch.
- Existing 4.0.5.2 installation unchanged.
- Shared Unity save folder backed up before launch under
  `PC_PVZ-Fusion-4.1/CodexBackups/before-customizelib41-20261110-181831/LanPiaoPiao`.

## Verified incompatibilities and changes

An unmodified source compilation against 4.1 failed with three errors:
`TravelDictionary.RogueBuffs`, `AlmanacBuffMenu.rogueBuffs`, and `RogueManager`
no longer exist. Inspected the real generated 4.1 API before changing these.

- Removed initialization of the obsolete Rogue buff set. The new native
  TravelRogueManager state is deliberately not reset or replaced.
- Legacy `AlmanacBuffType.Rogue` registrations remain AdvBuff entries and
  appear in General; the removed native Rogue tab is not fabricated.
- Removed the obsolete RogueManager.Clear call for entering custom levels.
  This does not port custom content to the new Rogue progression system.
- Assembly / loader metadata: `4.1.0-ml.1`; public assembly version unchanged.
- The metadata audit accepts an explicit expected release version; its
  previous 4.0.5.2 default is preserved.

## Validation

- Generated 4.1 interop assemblies successfully in the native loader.
- Compilation against 4.1: zero errors, 19 warnings (existing decompiled-source
  / compatibility issues; not presented as warning-free).
- Metadata audit: all 126 declared patch methods resolve against 4.1;
  no external BepInEx assembly reference. Audit does not apply native patches.
- DLL installed in 4.1 Mods; PvZ Fusion+ and other consumer mods not installed.
- Native startup test: MelonLoader loaded `CustomizeLib.MelonLoader v4.1.0-ml.1`,
  registered its injected components, and the native game reached `GameAPP.Start`
  (633 plant types / 1076 fusion recipes reported by the game). No ERROR,
  exception, or fatal message found in the saved loader/player logs.
- Nonfatal Il2CppInterop warnings remain: Class::Init signature fallback and
  managed extension-data methods with unsupported native parameter/return types.
- No keyboard/mouse automation used. No gameplay, custom plant registration,
  menu appearance, or complete consumer-mod compatibility claim.
- Matching source/installed SHA256:
  `9BC5B843620B146FE00930A74A6517C73664EFA1EF54EC93E95CBCDEA062BB39`.
- Startup logs saved beside the save backup as `customizelib41-startup.log`
  and `customizelib41-player.log`.
